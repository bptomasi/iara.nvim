# Third-party material

## base46 (NvChad)

The palettes in `lua/iara/theme/palettes/` are color values ported from
the base46 theme collection, <https://github.com/NvChad/base46>, under
the MIT license. The slot choices in `lua/iara/theme/groups.lua` follow
base46's integrations. No base46 code is included; each palette file
names the base46 theme it comes from and keeps that theme's credits to
its original author.
